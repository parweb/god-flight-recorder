# COUNCIL — protocole de décision contradictoire

Consigne observateur : ne pas décider bille en tête. Toute décision structurante passe par :

1. **ÉTUDE** — un agent énumère TOUT l'espace des options, chiffre, évalue l'automatisabilité. → `findings/<sujet>.md`
2. **CHALLENGE** — ≥2 agents red-team attaquent la conclusion sous des angles DIFFÉRENTS (chacun cherche à la RÉFUTER). → `bus/council/<sujet>-challenge-<angle>.md`
3. **SYNTHÈSE** — un agent réconcilie étude + réfutations, tranche, note la décision + ce qui la ferait changer. → `DECISIONS/<sujet>.md`

Règle : une conclusion qui ne survit pas à 2 réfutations sérieuses n'est pas adoptée.
Le décideur (PRIME) n'entérine qu'après le round de challenge.
