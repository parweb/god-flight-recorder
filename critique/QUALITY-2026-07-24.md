## Top fixes qualité — classés par impact

1. **[CRITIQUE] `meridian-demo.vercel.app` sert un site tiers non lié.** Vérifié (curl) : `<title>Meridian | WealthOS for modern wealth firms</title>` — un SaaS wealth-management, PAS le template MERIDIAN. Or les articles 01/03, les pins meridian et le Show HN pointent tous vers cette URL comme "le template MERIDIAN en live". Chaque clic dev.to/HN/Pinterest atterrit sur un site étranger → bounce, 0 conversion, image amateur. Le vrai fichier local `deploy/meridian-demo/index.html` est correct mais **n'est pas ce qui est déployé**. → Redéployer le vrai template sur un sous-domaine contrôlé (ou héberger `/meridian-demo` sous `1h-money-store.vercel.app`) **et** mettre à jour toutes les URLs (articles, pins, showhn, LISTING). Rien d'autre ne compte tant que ceci est cassé.

2. **[HAUT] Fausses preuves sociales spécifiques non marquées** — `product/meridian-saas/index.html` : "2,400+ founders shipping", "4.9★ average rating", testimonial **"Nadia Okonkwo, Founder, Rowan (solo)"** ; `product/flagship/index.html` : "98% of clients return". Un template pro est censé livrer des placeholders évidents, pas des chiffres et un nom de personne fabriqués qu'un acheteur ship tel quel = affirmation trompeuse à son insu. → Remplacer par placeholders marqués (`[2,400]+`, "Your customer quote here", `<!-- replace with your real number -->`).

3. **[HAUT] `navigator.clipboard` sans fallback** — `product/leverage/index.html` + `product/leverage-dev/index.html`. Ouverts en local (`file://`, exactement le "one file, no dependencies, yours to keep" vendu), le bouton "Copy" échoue en silence : pas de confirmation, rien dans le presse-papier. Casse la promesse cœur du produit. → Ajouter fallback `document.execCommand('copy')` + garder le feedback "Copied ✓".

4. **[MOYEN] Drift de nommage LEVERAGE (index.html ↔ prompts.md)** — deux fichiers du même pack payant qui se contredisent : catégorie 02 "Landing & Copy" (HTML) vs "Landing & Sales Copy" (md) ; 05 "Pricing & Money" vs "Pricing & Monetization" ; titre 4.2 "Voice extractor → style card" vs "Voice extractor". → Aligner sur une seule nomenclature.

5. **[MOYEN] MERIDIAN flagship sans finition SEO/partage** — aucun `<meta name="description">`, aucun OG/Twitter tag (le grader et /free en ont), liens footer morts, email texte non cliquable. Pour un template acheté pour être publié, la finition head est nulle. → Ajouter meta description + OG, rendre l'email `mailto:`, ou marquer les liens `#` comme "à câbler".

6. **[MOYEN] LEVERAGE//DEV — redondance qui gonfle le compte** — self-review (rule 20), adversarial reviewer (S.2) et adversarial diff review (R.1) se recouvrent à ~80%. Le "35 artefacts" est en partie du volume. → Différencier explicitement les 3 (règle always-on vs mode session vs prompt one-off) dans les titres, ou assumer/réduire.

7. **[BAS] Grader — faux positifs & heuristiques bricolées** — acronymes légitimes ALL-CAPS (SEO/API/B2B) pénalisés −4 pts ; bump specificity via `no`/`zero`/`\bx\b`. → Whitelister les acronymes 2–4 lettres connus ; retirer le bump `no`/`zero`.

8. **[BAS] Ambiguïtés prix** — Signal : hero "$29" lu comme one-time vs "/month" plus bas. MERIDIAN : "Sprint $4k/wk" sur un engagement annoncé "2-week" (= $8k ? confus). → Clarifier l'unité une seule fois.

## Les 3 à appliquer MAINTENANT

1. **Fix #1 — réparer/rediriger le lien démo `meridian-demo`.** Bloque *toute* la distribution meridian (articles + pins + Show HN prêts à publier envoient le trafic sur un site tiers). Aucun autre effort marketing ne convertit tant que c'est cassé.
2. **Fix #2 — marquer/retirer les fausses preuves sociales (Signal + flagship "98%").** Risque crédibilité/éthique immédiat : produits en vente qui font mentir l'acheteur. Édition inline, minutes.
3. **Fix #3 — fallback clipboard dans leverage + leverage-dev.** Répare la promesse centrale ("marche hors-ligne, un seul fichier") des deux produits les mieux notés. ~6 lignes chacun.
